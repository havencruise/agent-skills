# Decision Log

## {{TODAY}} — Use Markdown As Durable Memory

**Status:** Decided

**Decision:** Use version-controlled Markdown as the authoritative knowledge store.

**Why:** It is portable, searchable, inspectable, and compatible with many editors and agent environments.

**Consequences:**

- Conversational AI is treated as a convenience layer.
- Agents maintain files but do not become the source of truth.
- Sensitive secrets remain outside the repository.
