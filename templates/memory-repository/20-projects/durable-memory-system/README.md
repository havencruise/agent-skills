# Durable Memory System

## Outcome

Create a portable, searchable, AI-maintainable knowledge system.

## Why This Matters

Important decisions and context are distributed across chats, documents, and memory.

## Current State

- This repository is the canonical durable record.
- Agents may help maintain files.
- Git preserves history.

## Decisions

- Markdown is the canonical format.
- Git is the versioning system.
- Conversational AI is a convenience layer.
- Agents may edit files but must preserve history and uncertainty.
