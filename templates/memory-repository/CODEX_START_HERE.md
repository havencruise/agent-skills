# Agent Start Here

Open this repository in an agent environment and run these prompts in order.

## 1. Verify Repository Rules

> Read `AGENTS.md`, inspect the repository structure, and summarize how you will maintain this knowledge base. Do not change files yet.

## 2. Process The Inbox

> Process all unprocessed material in `00-inbox` according to `AGENTS.md`. Merge durable information into canonical notes, update indexes, preserve uncertainty, and show me the proposed diff. Do not commit.

## 3. Create A Weekly Review

> Create this week's review from the current repository using `_templates/weekly-review.md`. Summarize changes, decisions, stalled items, open loops, and the three highest-priority next actions. Do not invent missing information.

## 4. Repository Health Check

> Audit the repository for duplicate notes, stale project status, broken links, conflicting facts, missing review dates, and unprocessed inbox items. Produce a report without modifying files.
