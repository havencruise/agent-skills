## Principles

- Markdown is the source of truth.
- Conversational AI is a capture and maintenance layer, not the source of truth.
- Git preserves history.
- Sensitive secrets do not belong here.

## Start here

1. Open `HOME.md`.
2. Capture raw notes in `00-inbox/quick-capture.md`.
3. Ask an agent to process the inbox using `AGENTS.md`.
4. Review changes before committing.
